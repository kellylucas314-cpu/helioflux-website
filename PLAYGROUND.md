# HelioFlux playground

This branch is Kelly's sandbox copy of the HelioFlux site. Nothing here is live on helioflux.co.

- Live site: the `main` branch, served by GitHub Pages at helioflux.co.
- Playground: this `playground` branch, served by Vercel at
  https://helioflux-science-preview-git-playground-kellylucas314-cpus-projects.vercel.app
- Local folder: `/Users/kellylucas/Documents/GitHub/helioflux-playground` (a git worktree of the main site repo).

Every commit pushed to this branch updates the playground link and nothing else.
To take an idea live, copy just that change onto `main` (cherry-pick the commit or re-apply it),
rather than merging the whole branch, so experiments that were not approved never ride along.
